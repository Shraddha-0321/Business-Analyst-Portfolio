# JML (Joiner-Mover-Leaver) Identity Lifecycle Automation — IAM BA Sample
**Problem:** A fictional enterprise's manual JML process caused 3-day onboarding delays,
orphaned access after role changes, and multi-day gaps between employee termination and
account deactivation — creating audit and security exposure.
**What I produced:**
- A full BRD — stakeholders, functional/non-functional requirements, RBAC and SoD-aware
 acceptance criteria
- A Process Improvement Case Study — current/future-state process maps, 5-Whys root
 cause analysis, phased rollout recommendation
- A KPI dashboard — JML event volume, deprovisioning-speed trend against a 4-hour
 target, and SoD finding breakdown
**Outcome (modeled):** ~90% faster new-hire provisioning, ~85% faster offboarding
deactivation, and a shift from reactive audit findings to proactive SoD conflict detection.
